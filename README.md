# Proyecto Integrador - IFST 18

## Requisitos

- Python 3.10 o superior

## Instalación

1. Crear y activar un entorno virtual (Windows):

   ```
   py -m venv .venv
   .venv\Scripts\activate
   ```

2. Instalar las dependencias:

   ```
   pip install -r requirements.txt
   ```

## Uso

```
python app.py
```
